The original source distribution is retained alongside a locally built,
unmodified pure-Python wheel. The wheel is needed because Qiling depends on
unicodecsv and the Windows launcher installs binary distributions only.
No unicodecsv implementation has been changed. Upstream metadata, author
attribution, documentation and all packaged source files are preserved.
The release builder verifies the wheel's SHA-256 before packaging.
